# Imagens do README

Salve as capturas nesta pasta com exatamente estes nomes (o README já aponta para eles).
Prints em 1280×720 (tamanho nativo do jogo).

| Arquivo | O que capturar |
|---|---|
| `capa.png` | Hub com os portais (ou arte de capa com o título do jogo) |
| `selecao.png` | Tela de seleção de personagem (Alvares × Reis) |
| `hub.png` | Hub com o prompt de entrada de um portal em foco |
| `tutorial.png` | Setor 0: galpão no escuro ou painel de energia |
| `fase1.png` | Céu Partido: ilhas de mármore ou luta com o Helio |
| `fase2.png` | Porto Bugado: porto em chamas, guindastes ou chefe |
| `fase3.png` | Lixão Eletrônico: trecho com névoa/chuva ou Monstro de Sucata |
| `fase_final.png` | Mega Brain World: exterior da torre, andar ou forma do boss |
| `terminal.png` | Terminal aberto mostrando enunciado e deboche do Mega Brain |
